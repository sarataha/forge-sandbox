# forge-sandbox

Throwaway CLI for testing an agent workflow.

```bash
python3 -m sandbox greet ada
```

```bash
python3 -m sandbox ledger add 12.50 groceries --date 2026-10-03 --note market
python3 -m sandbox ledger list
```

```bash
python3 -m sandbox notes add "buy milk"
python3 -m sandbox notes list
python3 -m sandbox notes search milk
```
